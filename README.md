# Simplify

**캘린더와 다이어리를 한 화면에 둔 Mac 앱이에요.**

Google·iCloud 캘린더의 일정을 보고 고치면서, 그날·그 주·그 달에 붙은 메모와 할 일을 바로 옆에 적어요. 캘린더 앱, 메모 앱, 미리알림을 오가지 않고 Simplify 하나로 하루를 관리하는 게 목표예요.

> 만든 사람이 매일 쓰려고 만든 개인용 도구예요. 아직 내려받아 설치하는 배포판은 없고, 소스에서 직접 빌드해 써요. 빌드 방법은 [DEVELOPMENT.md](DEVELOPMENT.md)에 있어요.

---

## 이런 걸 할 수 있어요

### 📅 여러 캘린더를 한곳에서

- **Google 캘린더**(여러 계정)와 **iCloud 캘린더**를 함께 불러와 한 달력에 보여 줘요.
- **미리알림**의 마감일 있는 항목도 달력에 표시하고, 여기서 바로 완료 처리할 수 있어요.
- 주·월·년 보기를 오가고, 종일 일정은 위쪽 띠 줄에 고정돼요. 공휴일도 표시해요.
- 일정을 **만들고 고치고 지울 수** 있어요. 반복 일정은 "이 일정만 / 이후 모든 일정 / 모든 일정" 중에서 고를 수 있어요.
- 인터넷이 끊겨도 고친 일정은 기다렸다가 연결되면 보내요.

### 📝 하루·한 주·한 달 메모

달력 오른쪽 패널에서 **오늘, 이번 주, 이번 달** 탭을 골라 그 기간의 메모를 적어요. 한 기간에 메모를 여러 개 두고 탭으로 나눌 수 있어요.

메모는 다이어리처럼 계속 열어 두고 고치는 용도라 따로 저장 단추 없이 조용히 저장돼요. 서식도 넉넉하게 넣었어요.

- 굵게·기울임·밑줄·취소선, 글자색, 형광펜, 줄 안 코드
- 제목·머리말, 글머리·대시·번호 목록, 인용문, 정렬
- **표**: 엑셀·숫자·구글 시트·웹에서 복사한 표를 형식 그대로 붙여 넣을 수 있어요
- **수식**: LaTeX로 쓴 수식을 그려 줘요
- **파일 첨부**: 끌어 놓거나 붙여 넣으면 그림은 바로 보이고, 다른 파일은 카드로 붙어요
- **링크**: 주소를 붙여 넣으면 자동으로 링크가 되고, ⌘-클릭으로 열어요
- `────` 는 가로줄로, `11.02 08:30 …` 처럼 시각으로 시작하는 줄은 시각 칸에 맞춰 보여 줘요

메모를 크게 쓰고 싶으면 패널을 **넓게** 펼쳐요. 달력은 작은 달력으로 접히고 메모가 창을 거의 다 써요.

### ✅ 메모와 이어지는 할 일

할 일은 메모와 따로 놀지 않아요. **원본은 하나라서 어디서 체크해도 모두 같이 바뀌어요.**

- 메모의 줄을 골라 **할 일로 만들기** (⌘⇧T)
- 메모에서 `[[` 를 쳐서 기존 할 일을 **가져와 잇기**
- 끝내지 못한 할 일은 다음 날·주·달로 **넘기기**

### 🧩 위젯

바탕화면과 알림 센터에 둘 수 있는 위젯이 세 가지 있어요.

| 크기 | 보여 주는 것 |
| --- | --- |
| 작은 위젯 · 다음 일정 | 오늘 날짜와 다음 일정 두 개 |
| 중간 위젯 · 오늘 | 오늘 남은 일정과 다가오는 일정 |
| 아주 큰 위젯 · 이번 달 | 이번 달 달력, 다가오는 일정, 오늘 할 일 (위젯에서 바로 체크) |

위젯의 날짜를 누르면 앱에서 그날이 열려요.

### 🔄 기기끼리 맞추기

설정에서 iCloud Drive 폴더를 하나 고르면, 같은 Apple 계정을 쓰는 다른 Mac과 메모·할 일·첨부 파일·설정을 맞춰요. 두 기기에서 같은 메모를 고쳤으면 어느 한쪽 글도 버리지 않고 둘 다 남겨요.

### 🗒️ Apple 메모로 남기기

원하면 Simplify에 쓴 메모를 Apple 메모 앱의 `Simplify` 폴더에도 같은 내용으로 써 둬요. 메모 앱이 iCloud로 맞춰져 있으면 iPhone에서도 읽을 수 있어요. 한쪽 방향이라 메모 앱에서 고친 내용은 Simplify로 돌아오지 않아요.

## 디자인

화면은 **"잉크 장부"** 방향이에요. 달력과 메모 패널이 한 장의 종이처럼 이어지고, 그 사이에 굵은 잉크 줄 하나만 있어요. 틀은 흑백으로 조용히 두고, **색은 내 캘린더 색에만** 써요. 빨강은 공휴일과 되돌릴 수 없는 동작(삭제 같은)에만 써요.

- 라이트와 다크(따뜻한 회갈색 "흑연") 테마
- 캘린더마다 색과 모양을 직접 고르고, 색을 구분하기 어려우면 **패턴도 함께 표시**할 수 있어요
- 주 시작 요일(일요일·월요일)을 고를 수 있어요
- 키보드만으로도, 마우스만으로도 모든 일을 할 수 있게 만들고 있어요

## 자주 쓰는 단축키

| 단축키 | 하는 일 |
| --- | --- |
| ⌘N | 새 일정 |
| ⌘T | 오늘로 가기 |
| ⌘← / ⌘→ | 이전·다음 주(달, 해) |
| ⌘1 / ⌘2 / ⌘3 | 주·월·년 보기 |
| ⌘\\ / ⌘⇧\\ | 메모 패널 숨기기 / 넓게 |
| ⌘⇧T | 고른 줄을 할 일로 만들기 |
| ⌃⌘T | 지금 시각 줄 넣기 |
| ⌘K | 링크 넣기 |
| ⌥⌘E | 수식 넣기 |
| ⌘⇧A | 파일 첨부 |
| ⌘, | 설정 |

## 내 데이터는 어디에

- 메모와 할 일은 **이 Mac 안에** 저장해요. 따로 운영하는 서버는 없어요.
- 캘린더 계정 로그인 정보는 이 Mac의 **키체인에만** 저장해요.
- 기기끼리 맞추기를 켜면 **내가 고른 iCloud Drive 폴더**에만 파일을 써요.
- 일정은 원래 캘린더(Google·iCloud)가 원본이라, Simplify에서 고친 일정은 그 서비스에 바로 반영돼요.

## 필요한 환경

- macOS 26 이상
- Google 캘린더를 쓰려면 Google 계정, iCloud 캘린더를 쓰려면 Apple 계정의 앱 전용 암호

## 앞으로

- iPhone 앱 (같은 데이터와 디자인으로)
- 다른 사람도 쉽게 설치할 수 있는 배포판
